# Ikaros 🚀

> 基于 **纯 Rust (Clean Architecture + MVI)** 与 **Slint UI** 构建的现代化高性能 Android 设备桌面管理与实时投屏调试平台。

---

## 🌟 核心特性

1. **设备监控与概览**
   - 自动检测在线 Android 设备与热插拔监听 (`host:track-devices`)；监听因 ADB Server 重启等原因断开时，每隔 2 秒自动尝试重连，断开与恢复时显示状态提示。
   - 左上角设备列表支持右键「复制序列号」，复制所点击设备的原始序列号，并保持当前设备选择。
   - 实时读取设备品牌、型号、Android 系统版本、API 级别、CPU 架构、电池状态与屏幕分辨率。
   - 设备概览显示 Wi-Fi IP、本机 Wi-Fi MAC 与蓝牙 MAC，点击卡片即可复制；Wi-Fi MAC 为当前连接使用的地址（可能是随机地址），系统未提供的地址显示“无法获取”。
   - 快捷工具：一键截取屏幕（PNG）、按 15/30/60 秒录制屏幕（MP4）、生成 Bug 报告（ZIP），产物统一保存到 `~/Downloads/Ikaros/`。
   - 无线调试：输入 `IP:端口` 远程连接设备，支持断开连接与一键让设备端开启 TCP/IP 模式（`tcpip 5555`）后改为无线连接。
   - 「设备概览」页的无线调试区域显示最近使用的连接地址，自动去重、最新在前，最多保留 8 条并在重启后恢复；点击历史地址回填输入框，再点击「连接」发起连接。

2. **外部 Scrcpy 一键投屏**
   - 直接调用本机官方 **scrcpy** 客户端（可自定义本体路径），投屏窗口由官方程序独立承载，天然支持音频、h265/av1、剪贴板与完整键鼠操控。
   - 本体路径支持手输，也可点击"浏览"按钮通过系统 Finder 原生文件夹选择器直接定位。
   - scrcpy 本体路径修改后立即持久化（macOS 保存于 `~/Library/Application Support/Ikaros/config.json`），重启应用自动恢复；也可在「设置」页统一管理。
   - 可视化参数：分辨率上限、帧率、码率、视频编码、音频转发、屏幕常亮，一键传递给官方客户端。
   - 自定义参数输入框：任意 scrcpy 命令行参数以空格分隔透传（支持引号包裹含空格的路径），例如 `--new-display=1920x1080 --turn-screen-off`。
   - 自定义参数 Tag：输入参数后点击"存为 Tag"即可保存（一个 Tag 对应一个参数，持久化到本地配置），点击 Tag 追加/移除参数，Tag 上的叉号可删除。悬停显示参数作用，支持 `-Sw` 等短参数组合。
   - Tag 勾选状态与自定义参数在修改后自动保存，重启应用时恢复；取消勾选或清空参数后也会保存最新状态。
   - 投屏页可展开常用参数对照表，按 scrcpy v5.0.1 官方文档整理，支持复制参数示例及打开对应官方文档。
   - 支持多设备同时投屏，切换设备只更新当前选择并保留已有投屏窗口；新投屏通过「一键启动投屏」手动启动，切回已有会话的设备时复用原窗口，「停止当前设备投屏」只影响当前选中的设备。

3. **ADB Sync 极速双向文件管理**
   - 直连 ADB Server TCP（`127.0.0.1:5037`）底层二进制 Sync 协议（`STAT`/`LIST`/`RECV`/`SEND`/`QUIT`）。
   - 单击进入文件夹，列表显示名称、类型、大小与修改时间；点击表头可按名称、大小或修改时间正序/倒序排序，目录始终排在文件前面。
   - 支持新建文件夹、删除文件/文件夹、同目录重命名（带输入浮层与原名预填）；危险操作均有确认提示。
   - 右键文件下载到电脑，右键文件夹或空白处选择文件上传，也可复制完整路径；上传与下载均显示实时进度条与状态信息。
   - 文件下载默认保存到 `~/Downloads/`；点击文件管理器顶部的「📥 下载目录」可选择其他保存目录，设置自动保存并在重启后恢复。
   - 传输时可点击进度条旁的「取消」中止当前上传或下载，取消下载时清理未完成的本地文件；同一时刻只允许一个文件上传或下载任务，重复发起时提示先取消当前传输。

4. **应用管理与拖拽 APK 释放安装**
   - 极速分类筛选已安装应用（全部应用 / 系统应用 / 第三方应用），默认显示全部应用。
   - 显示设备当前语言的应用名、真实图标、包名和版本；支持按应用名或包名实时搜索，点击包名或版本名称复制，右键打开操作菜单。
   - 一键启动应用、强行停止、清除数据、卸载应用、反向提取备份 APK 到本地。所有应用的右键菜单均提供卸载入口；系统应用显示“卸载（当前用户）”，只从设备当前用户移除，卸载成功后自动刷新列表。
   - 单击应用图标、应用名或行内空白启动应用，包名与版本名称保留点击复制。启动时解析当前用户的 Launcher 入口；系统设置优先打开设置首页，并兼容将 Launcher 配置为子页面的设备。无启动入口或启动被系统拒绝时显示失败原因。
   - **拖拽安装**：在电脑中拖拽任何 `.apk` 文件释放至应用窗口，自动通过 ADB Sync 高速推流并调用 `pm install -r -t` 完成静默安装，随后自动刷新应用列表。

5. **Logcat 高性能日志流与搜索**
   - 结构化 threadtime 解析（时间戳、PID、TID、日志级别、Tag、正文）。
   - 环形缓冲队列（50,000 条），根据日志级别（V/D/I/W/E）与关键字实时无损过滤渲染。
   - “滚动到底部”后持续跟随最新日志；手动滚动或选择日志时锁定当前阅读视图，后台抓取和本地保存继续运行。有新日志时显示提示，点击“回到最新并跟随”恢复实时显示。
   - 支持“自动换行”开关；开启时按可见宽度完整换行，关闭时保留单行并支持横向滚动查看长日志。
   - 日志按时间戳、包名、级别、Tag、正文排列；后台按 PID 与 UID 关联应用。无法确定包名的系统进程显示进程名，未知来源显示“—”。包名也会写入本地日志。
   - 输入有效的 `package:`、`tag:` 正向筛选时，自动隐藏对应列；级别选择非「全部」时隐藏级别列，空出的空间用于显示正文。清除筛选后自动恢复；仅使用排除条件或普通关键字时保留对应列。「复制整条日志」、导出和本地记录仍保留完整字段。
   - 在日志的包名、Tag 或正文列右键，可将该单元格的值加入上方过滤栏，保留已有条件并自动处理引号、空格及重复条件；级别列右键可联动上方级别按钮（按该级别及以上筛选，F 归入 E/F）。时间戳列提供原有复制操作，无法确定真实包名的记录不提供包名筛选。
   - 筛选支持 `package:com.example timeout`、`package:com.example message:"network timeout"` 等组合；`package:`、`tag:`、`message:` 可组合使用，同一字段的多个正向条件为“或”，不同字段为“且”，支持 `-package:` 等排除条件。
   - 筛选框支持上述字段及其排除条件的前缀自动补全；输入 `pa` 或 `-` 显示候选，可点击或使用方向键选择、Enter / Tab 填入，Esc 收起。
   - 筛选框末尾的「清空」按钮可一键清除文本过滤条件并刷新日志，清空后可直接继续输入。
   - 可开启“同步保存到本地”，后台保存全部收到的日志，不受界面筛选或历史条数限制；按设备与抓取会话生成 `.log` 文件，并可一键打开日志文件夹。macOS 默认目录为 `~/Library/Logs/Ikaros/logcat`。
   - 开关状态与日志会在重启后保留；明确关闭开关时，停止写入并清理本功能生成的日志文件。磁盘写入失败会暂停抓取并保留已有文件，方便备份。
   - 一键导出当前筛选结果为 `.log` 文件，保存到 `~/Downloads/Ikaros/`，所见即所得。

6. **交互式 ADB 终端**
   - 原生支持交互式执行远程 shell 命令并实时流式输出，长命令运行期间可随时点击"停止"中断。
   - 输入框上方的 ⬆/⬇ 按钮（或键盘上下键思路）可在本会话执行过的命令历史中翻阅，回车即重新执行。

7. **设备与应用性能监控**
   - 设备整体 CPU、内存已用/总量、电量、电池温度与网络收发速率（聚合所有非回环网卡）；选择已安装应用或输入包名，监控应用 CPU、PSS 内存、UI 绘制 FPS 和卡顿帧比例。
   - 后台每 2 秒采样，曲线保留最近 120 次；支持暂停/继续，离开页面自动停止采样，切换设备或应用后重新建立基线。
   - CPU 以整机容量 100% 计，应用 CPU/PSS 合计主进程和以包名加冒号命名的子进程。UI FPS 基于 HWUI 绘制统计，不代表屏幕刷新率，不包含 SurfaceView、游戏等独立渲染；不可用指标显示“—”。
   - 支持将本次全部采样历史导出为 CSV 文件，保存到 `~/Downloads/Ikaros/`，便于离线分析。

## 🏗️ 架构设计

严格贯彻 **Clean Architecture（整洁架构） + MVI（单向数据流）**：
```
├── crates/ikaros-domain   # 核心业务实体与 Trait 契约（无外部框架依赖）
├── crates/ikaros-usecase  # 纯业务用例（用例调度与防腐层）
├── crates/ikaros-adb      # ADB TCP 通讯协议与底层实现
└── crates/ikaros-app      # Slint 1.18 客户端 UI、MVI 状态机与外部 scrcpy 启动器
```

## 🖥️ 快速运行与打包

### 1. 命令行快速开发运行
```bash
cargo run --bin ikaros
```

应用名称和图标通过内嵌的只读 DEX 辅助程序读取，无需在设备上安装 APK，普通 Cargo 构建也不依赖 Android SDK。修改 `crates/ikaros-adb/device-helper/PackageMetadata.java` 后，需要使用 JDK 及 Android SDK 重新生成辅助程序：

```bash
python3 scripts/build_package_helper.py
```

macOS 提供原生“窗口”菜单，支持最小化、缩放，以及当前系统可用的居中、填充与窗口平铺操作；窗口位置与大小会自动保存，重新启动时恢复。

### 2. 打包生成原生 macOS 应用程序 (.app)
项目自带一键打包脚本，会自动进行 Release 优化编译、生成 macOS 规范的 Retina 多分辨率图标（`AppIcon.icns`）并装配到系统应用程序：
```bash
./scripts/build_app.sh
```

图标采用深蓝底色与冰蓝飞翼造型。`assets/icon_1024.png` 是唯一主图，打包时会在主图或生成脚本更新后自动重新生成多分辨率图标包；也可手动运行 `python3 scripts/generate_icon.py`。

构建完成后产物位于：
- **应用程序目录**：`/Applications/Ikaros.app`
- **项目独立产物**：`dist/Ikaros.app`

打包脚本会覆盖已有的 `dist/Ikaros.app`，并在成功后执行 `cargo clean` 清理 `target/`，只保留最新应用产物；下次构建会重新编译依赖。

可以通过以下方式直接启动：
* 按下 `Cmd + 空格`（Spotlight）或 Raycast，输入 `Ikaros` 回车打开；
* 在 Finder 的“应用程序”中双击 `Ikaros.app`；
* 将其拖入 macOS Dock 栏常驻。
